# Сайт-портфолио Дмитрия Майорова

Сайт собран на Astro. Он адаптивный: 1280px и шире, планшеты и телефоны от 360px.
Кейсы и тексты главной редактируются в браузере через админку (Sveltia CMS) по адресу `/admin`.

## Что где лежит

| Что | Где |
|---|---|
| Тексты главной (имя, «Фокус», факты, опыт, навыки, ссылки) | `src/data/home.json` |
| Кейсы — один файл на кейс | `src/content/cases/*.md` |
| Картинки кейсов | `public/uploads/cases/<кейс>/` |
| Обложки карточек, фото | `public/uploads/covers/`, `public/uploads/home/` |
| Стили | `src/styles/global.css` |
| Настройки админки | `public/admin/config.yml` |

## Как устроен кейс (как в Behance)

Кейс состоит из **блоков**, которые идут сверху вниз. Есть четыре вида блоков:

- **Картинка** — секция, выгруженная из Figma. Можно загрузить две версии: для компьютера (ширина 1280 или 2560) и для телефона (375 или 750). На телефоне сайт сам покажет мобильную.
- **Текст** — заголовок и абзацы.
- **Галерея** — 2–4 картинки в ряд.
- **Видео или прототип** — ссылка на YouTube, Vimeo или прототип в Figma.

### Как выгрузить секции из Figma

1. Выдели фрейм-секцию.
2. В панели **Export** выбери `JPG` или `PNG` и масштаб `2x`.
3. Нажми **Export**.

Секции десктопа и мобилки грузи парами в один блок.

## Публикация (один раз)

1. Заведи аккаунт на github.com.
2. Создай публичный репозиторий с именем `ЛОГИН.github.io` (вместо ЛОГИН — твой логин).
3. Залей в него эту папку. Это делается через GitHub Desktop или кнопкой **Add file → Upload files**. Папки `node_modules`, `dist`, `_preview` загружать не нужно.
4. Открой репозиторий → **Settings → Pages → Source: GitHub Actions**.
5. Через 1–2 минуты сайт появится по адресу `https://ЛОГИН.github.io`.
6. В файле `public/admin/config.yml` замени `YOUR_GITHUB_LOGIN` на свой логин в строке `repo`.

После каждого изменения (из админки или вручную) сайт пересобирается и обновляется сам за 1–2 минуты.

## Вход в админку

1. Открой `https://ЛОГИН.github.io/admin/`.
2. Нажми **Sign In Using Access Token**.
3. Токен создаётся так: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
4. В настройках токена:
   - Repository access: только репозиторий сайта.
   - Permissions → **Contents: Read and write**.
5. Скопируй токен и вставь его в админку. Он запоминается в браузере.

Без интернета можно работать так: **Work with Local Repository** → выбрать эту папку. Нужен Chrome или Edge. Изменения сохранятся в файлы на компьютере.

## Запуск на компьютере (необязательно)

Нужен Node.js 22. Команды:

```
npm install
npm run dev      # сайт на http://localhost:4321
npm run build    # готовый сайт в папке dist
```
